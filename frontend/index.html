O que é um token e um lexema?

O scanner (analisador léxico) é a primeira fase do compilador. Ele lê o código caractere a caractere e agrupa os caracteres em lexemas, como while, contador ou <=.

Cada lexema recebe uma categoria e vira um token: while é PALAVRA_RESERVADA, contador é IDENTIFICADOR e <= é OPERADOR_RELACIONAL. Espaços e comentários são lidos, mas descartados.

Em Python a indentação define os blocos, por isso o scanner também produz tokens sem texto: NOVA_LINHA no fim de cada instrução, INDENT quando um bloco começa e DEDENT quando ele termina.

Subconjunto aceito: atribuições, números inteiros e reais, strings, + - * / %, == != < <= > >=, if/elif/else, while, True/False, print e blocos por indentação. A árvore sintática chega na Etapa 4.
